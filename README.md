## 🍷 Project 1: Red Wine Quality Data Analysis

*(Current Project)*

In this project, I performed a comprehensive Exploratory Data Analysis on the physicochemical properties of red wine variants. The goal was to understand the factors that influence wine quality and classify wines based on these attributes.

### 🛠️ Tools & Technologies Used:
- **Python:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Statistical Analysis:** Correlation matrices, distribution analysis
- **Environment:** Jupyter Notebook / VS Code

### 🔍 Key Objectives:
- To clean and preprocess the raw dataset for analysis.
- To visualise the distributions of chemical properties (e.g., acidity, sulphates, alcohol).
- To explore correlations between specific chemical features and the quality score.
- To identify key drivers that separate high-quality wines from standard ones.

### 📈 Key Insights Uncovered:
*(You can update this section post-analysis with your specific findings, e.g., "Higher alcohol content shows a strong positive correlation with higher quality ratings.")*

> **Insight:** Exploratory analysis revealed that specific chemical balances (particularly alcohol and sulphates) play a significant role in determining the final quality score of red wine.
